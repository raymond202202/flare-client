Flare —— Windows 7 兼容版（内置 .NET 运行时）
================================================

这个包和标准版有什么不同？
  · 标准版（flare-VERSION-win-x64-setup.exe，约 4MB）
      依赖系统自带的 .NET Framework 4.8。
      适用于 Windows 10 / 11（系统已自带 4.8），体积最小、启动最快。
  · 兼容版（本包，flare-VERSION-win-x64-compat-setup.exe，约 40MB）
      把 .NET 6 运行时（CoreCLR + WPF + UCRT）整个打进安装包，
      目标电脑【不需要安装任何额外组件】。
      适用于 Windows 7 SP1 / 8 / 8.1，以及不愿折腾运行时的 Windows 10 / 11。

  ★ 两个版本装到同一个位置，二选一安装即可。
    换版本时先卸载旧的，再装新的（安装程序会自动结束正在运行的 Flare）。

系统要求
  · Windows 7 SP1 及以上，64 位（x86 32 位系统不支持）
  · Win7 若从未打过任何系统更新，建议先装 SP1；本包已自带 UCRT，
    无需再装 .NET Framework 或 KB3063858 / KB4474419 等补丁
  · 不需要管理员权限：装到当前用户目录，不弹 UAC
  · 不需要 Node.js，不需要联网即可使用

安装 / 卸载
  安装：双击 setup.exe，一路下一步；完成页可直接启动
  卸载：开始菜单 → Flare → 卸载 Flare，或「设置 → 应用 → Flare」卸载
  静默安装（企业批量）：setup.exe /S
  静默卸载：Uninstall.exe /S

----------------------------------------
以下为通用使用说明
----------------------------------------

==================

Flare 是一个本地优先的 AI 助手客户端。这个包里已经带好了引擎，
你不需要安装 Node、Python 或任何运行时，也不需要关心版本号。


一、运行
--------

解压后双击 Flare.exe 即可。

首次启动它会：
  · 在  %USERPROFILE%\.flare\  下建好数据目录；
  · 如果还没有配置，会在界面里引导你填 API Key。

如果你的 Windows 弹出「已保护你的电脑」（SmartScreen），
点「更多信息」→「仍要运行」即可。这是因为安装包还没买代码签名证书，
不是病毒。


二、目录结构
------------

  Flare.exe            图形界面
  Flare.exe.config     运行时配置（不要删）
  Newtonsoft.Json.dll  依赖库（不要删）
  engine\flare.exe     内置引擎（不要删）

这四个文件必须放在同一个文件夹里。把这个文件夹整体搬到别处也能用，
放到 D 盘、U 盘都行，不会写注册表。


三、命令行怎么用
----------------

如果你想要纯命令行版本（没有图形界面），去下载 engine 包，
里面只有 flare.exe 一个文件，可以直接：

  flare.exe              进入交互式对话
  flare.exe --help       看所有参数
  flare.exe --version    看版本号


四、数据在哪
------------

  %USERPROFILE%\.flare\            配置与会话记录
  %USERPROFILE%\.flare\.env        你的 API Key（别外传）

卸载就是删掉解压出来的文件夹和上面这个目录，没有残留。


五、出问题了
------------

把它从一个终端里启动，可以看到日志：

  cd 到 Flare.exe 所在目录
  .\Flare.exe

报错信息复制给我们即可。
